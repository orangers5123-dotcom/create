# 2026-11-03 打ち合わせメモ（高橋さん共有の内容を整理）

## 1. 伸びている動画を真似る（ジャンルを問わない）
- 答えは市場に落ちている。企画を頭の中で考えない、自分で考えるのをやめる
- 伸びている動画の編集・企画・冒頭フックを真似する。固定概念に囚われず、真似できる部分はどんどん取り入れる（ほどよく）
- 例：「この動画が伸びていたから、この動画の編集を真似した」
- 冒頭フックの成功例：カメラに向かってパンチするような動き
- 伸びているトレンドを導入する
- 伸びた動画（型）は何回も擦る

## 2. ブランド
- たかさんには「ガレージの人」になれる要素がある。「ガレージと言えばたかさん」を作る
- 課題：「たかさんの動画だから見よう」が弱い

## 3. 案件（PR）
- 案件動画が直接的すぎる。案件の説明をメインにせず、企画の中で補足として挟む（デメリット：手間がかかる）
- 単品紹介は弱い
- 企業に大量にメールを送る（営業）

## 4. 視聴者・見せ方
- 初めて見てくれた人を落とさない施策を考える
- ペルソナ：誰に向けた動画かを決める
- 見どころのポイントを作る。見どころがなければその企画はやらない
- ホスピタリティ・情報提供を大事に：値段やサイズを分かりやすく表示、保存ポイントを作る
- 視聴者に共感してもらうためのリアルの見せ方

## 5. 企画の候補
- 賃貸で壁に穴をあけられない人向けの、プロジェクター設置のノウハウ
- お部屋づくりの知見の紹介
- 書斎改造：前編・後編に分けるか、1本の長尺にするか（要検討）

## 6. 多言語化
- YouTube Studioの「言語」から、サムネとタイトルを英語に置き換える（投稿後に設定）
