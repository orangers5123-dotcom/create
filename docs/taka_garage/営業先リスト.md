## 調べ方と注意（必ず読む）

| 項目 | 内容 |
|---|---|
| PR実績の根拠 | YouTubeの検索結果（2026/11/3取得）に出る**概要欄の冒頭の文**に「提供：◯◯」「商品提供」「【PR】」があるものを記録した。動画の公開時期は11/3時点の「◯か月前」表示 |
| 確認できなかったこと | YouTubeの動画ページ（watch）は自動アクセスの確認画面に切り替わり開けなかった（回避はしていない）。そのため**「有料プロモーションを含みます」表示の有無はすべて未確認**。概要欄の「【PR】」がアフィリエイトリンクの表記である可能性もある（下の表では「提供」表記を優先して載せた） |
| 会社の規模 | 主に **PR TIMES のプレスリリース末尾の会社概要**（設立・資本金・所在地）と、各社公式サイトの会社概要ページ。**従業員数はほぼ未確認**（分かったのはセイワ89名のみ）。「中小企業」の判断は資本金・設立年・日本法人の有無からの目安 |
| 問い合わせ窓口 | 公式サイトのリンクを実際に開いて確認したURLだけ載せた。メールアドレスは公式サイトに公開されているもの（マーケティング・メディア・KOL向けを優先）だけ。個人の連絡先は載せていない |
| 使っていないもの | User-Agentの偽装などボット対策の回避はしていない |
| 法令 | 依頼を受けたら、冒頭の口頭PR表記＋YouTubeの「有料プロモーション」設定（景品表示法のステマ規制）。**SOXAI（睡眠・体調の記録）・RingConn**など健康に触れる製品は薬機法に注意（「健康になる」「睡眠が改善」などの効果をうたわない） |

**優先度の基準**

- **A**：ガレージ・工房・車・書斎の「悩みを解く企画」に自然に入る＋同じジャンルのチャンネルで直近1年以内の提供実績あり＋日本の窓口がはっきりしている
- **B**：相性は良いが、提供実績が古い／日本の窓口が海外本社のみ／企画が書斎・シアター寄り
- **C**：相性が一部だけ（デスク小物・オーディオなど）、または実績が古い・薄い。まとめ回（「1万円以下で秘密基地が変わる15選」など）の中の1枠向け
