# ショートの冒頭0.2秒の作り直し（3Dプリンター作業台ショートの反省から）

- 状態：未反映
- 書いた日：2026-11-04
- 書いた人：編集連携担当（taka-edit-liaison）／高橋さんのフィードバック
- 優先度：高
- 適用範囲：ショートすべて（次の日曜のショートから）
- いつから：次のショートから。3Dプリンター作業台ショートを作り直す場合はそれにも

## なぜ（背景と根拠）
- 高橋さんの判断：ショートは、スワイプする手を止めるために **最初の0.2秒が勝負**。いかにキャッチーな見た目で目を惹きつけるか。初手から効果音を入れる
- 11/4公開の3Dプリンター作業台ショート（36秒）の分析：
  - 0〜3秒：完成したラックの同じ画が3秒止まったまま。寄り・カット・動きなし。音はBGMだけ（声は3.0秒から。冒頭に効果音なし）
  - 7.5〜12.9秒：騒音の話をしているのに、静かな完成形が約5秒止まったまま
  - 12.9〜22秒：作業の早回しは約1.25秒ごとに切り替わっているが、音はBGMだけで効果音なし
  - 「何の動画か」が冒頭で伝わらない（完成形だけでは、問題も変化も分からない）
- クラウド側の指示も「0〜0.5秒は完成形」としていた。完成形の静止画から入る設計自体が弱かった

## 何を変えるか（ショートの冒頭の新ルール）
1. **0.0秒目から効果音**（インパクト系の「ドン」「バン」など）。BGMだけで始めない
2. **0.0秒目から動きのある画**：ズームイン（約110%→100%を0.2秒で）、揺れ、物が動く・倒れる・叩く、たかさんの動き（パンチ・指さし）のどれか。止まった画で始めない
3. **一番インパクトのある「問題」か「変化」の画から入る**：完成形の静止画ではなく、曲がった机・暴れるプリンター・騒音・Before→Afterの一瞬の切り替えなど、「えっ？」となる画
4. **0.2秒以内に大きな文字で「何の動画か」**：短く具体的に（例「3Dプリンターで机が崩壊」「机が曲がった」）。上の見出しは、画面の上1/4に大きく
5. **0〜1秒の間にBefore→Afterを一瞬見せる**（結果の約束）：例「机が崩壊 → 一歩で工房」
6. 1〜3秒で問題の続き（声）。声は1秒以内に入れる
7. 2秒以上同じ画を止めない。作業の早回しにもカットごとに効果音（「シュッ」「カチャ」など）
8. 字幕は画面の真ん中より少し下まで（下の約3分の1はYouTubeのボタン・タイトルで隠れる）。同時に出す文字は2か所まで

## 3Dプリンター作業台ショートを作り直す場合の冒頭（例）
| 秒 | 画 | 音 | 文字 |
|---|---|---|---|
| 0.0〜0.4 | 曲がった机のアップに急ズーム（または机の上で揺れるプリンター） | 「ドン」＋プリンターの動作音 | 「3Dプリンターで机が崩壊」（大きく） |
| 0.4〜0.9 | 完成したラックに一瞬切り替え（フラッシュ） | 「シャキーン」系 | 「→ 一歩で工房」 |
| 0.9〜3.0 | 机の曲がりを指さす（元の3〜5.5秒の素材） | 声「こうしてみると机の曲がりやばい」 | 字幕 |
| 3.0〜7.0 | 動作中のプリンター、騒音（耳をふさぐ等） | プリンター音＋声 | 「音もうるさい」 |
| 7.0〜 | 撤去→組み立て→運ぶ（カットごとに効果音）→完成→本編へ | | |

## DaVinciでの目安
- ズームインはインスペクタのズームにキーフレーム（0フレーム目110%→5フレーム目100%前後）。手元のやり方を優先（要確認）
- 効果音の音量は -20〜-25dB、BGMは -30dB前後（冒頭の効果音は少し大きめでもよいが、ピークが-1dBを超えないように）
