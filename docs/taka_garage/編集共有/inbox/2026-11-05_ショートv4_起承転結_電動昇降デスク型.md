### 手本の起承転結
| | 秒（手本） | 中身 |
|---|---|---|
| 起 | 0〜4.5 | 「いらないと思ってた」＝前の思い込み（見出しで問いを立てる） |
| 承 | 4.5〜17 | 「使ってみると意外や意外、次も電動昇降デスクが良くなります」と先に結論→理由1（配線整理が楽） |
| 転 | 17〜40 | デスクの下に潜って実演（動き）→「在宅ワーカーでもないのに…肩こりが起こる」と自分の話に転じる |
| 結 | 40〜50 | 「座りっぱなしを防いでリフレッシュ」「これ意外と侮れない」→本編のサムネ |

伸びた理由（根拠の種類つき）：
- 見出しが「〜と思ってた結果」＝前の思い込みと結果の差。最後まで出ているので、どこから見ても何の動画か分かる（自チャンネルのデータ：この回が61.9%で最高。心理学：情報ギャップ、Loewenstein 1994）
- 0.0秒から本人の声。人の声は効果音より「誰かが自分に話している」と感じさせる（仮説。v4とv2の数字で確かめる）
- 結論を先に言ってから理由（承の頭で答えを出す）ので、見る人が迷わない
