## v2の失敗から変えること（全カット共通）
| 変えること | 理由（v2で実際に起きたこと） |
|---|---|
| 秒数は目安。**カットは動作の切れ目で入れる**（動き出し・置く・ドアが開く等）。秒数に合わせて素材を伸ばしたり切ったりしない | v2は秒数指定に合わせたため、人のいない机の板（9〜10.5秒）、空のラック（13〜14.5秒）、見切れ（18.8〜25秒）が映った |
| 人も動きも無い画は使わない（素材一覧で「いない」「ほぼ固定」の画は、プリンター作動中の寄りだけ例外） | 同上 |
| 黒い画面・無音・同じ画2秒以上は入れない | v2の7.5秒の黒い画面と18秒の無音で勢いが止まった |
| 足す効果音より、素材の実際の音（ドアの開閉・ハンマー・電動ドライバー・プリンター動作音）を上げる | 実音は画と一致するので、作り物の効果音より違和感が無い。v2は効果音が多くうるさかった |
| 文字は「上の見出し1つ＋字幕」まで | v2も概ね守れていたので継続 |
