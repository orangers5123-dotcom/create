リサーチや打ち合わせで決まった「編集の変更」を、手元のパソコンでDaVinci Resolveの編集をしているClaude Code（たかさん専用の編集をメモリに覚えているもの）へ渡すための場所です。

- 手元への一言：「このページの今回の指示で編集して：（URL）」
- inbox・編集ルール.md は、クラウド側の記録として引き続き使う

## しくみ（Git経由の元の案）
1. クラウド側の **編集連携担当（taka-edit-liaison）** が、決まった編集の変更を `inbox/` に1件1ファイルで書き、`編集ルール.md`（いま有効な編集ルールの一覧）を更新して、このブランチにpushする
2. 手元のClaude Codeが `git pull` で取り込み、`inbox/` の「未反映」のものを読んで、自分のメモリ（たかさん専用の編集ルール）に反映する
3. 反映したら、そのファイルの「状態」を「反映済み」に変え、反映日とメモ（手元の既存ルールとぶつかった点など）を書いてpushする

## 逆方向（手元 → クラウド）
4. 手元のClaude Codeに `手元のClaude Codeへの書き出し依頼.md` を貼ると、メモリにある「たかさん専用の編集ルール」を `手元の編集ルール.md` に書き出してpushする
5. クラウド側の編集連携担当がそれを読み、`編集ルール.md` と突き合わせて、新しい編集の施策を考え、`inbox/` に提案として書いて返す（→ 1〜3の流れに戻る）
