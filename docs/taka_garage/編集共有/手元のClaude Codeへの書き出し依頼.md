# 手元のClaude Code（DaVinci×YouTube）に貼り付ける「編集ルールの書き出し依頼」

以下を、手元でDaVinci Resolveの編集を担当しているClaude Codeに貼り付けてください。

---

クラウド側のAI社員（編集連携担当）と、たかさん専用の編集ルールを共有したいです。あなたがメモリやCLAUDE.mdに覚えている「たかガレージ秘密基地の編集ルール」を、すべて書き出してください。

1. このリポジトリで `git fetch origin claude/taka-garage-handoff-u1fvxt` を行い、そのブランチに切り替える（mainにマージ済みならmain）
2. `docs/taka_garage/編集共有/手元の編集ルール.md` を開き、見出しに沿って、覚えている内容をすべて書き込む
   - メモリ、CLAUDE.md、設定ファイル、これまでの編集で決めたこと（davinci_auto_cut などのツールの設定値も含む）から集める
   - 数値（フォント名・サイズ・色・位置・秒数・dB・fps・解像度など）は、覚えている通りに正確に書く
   - 覚えていない・決まっていない項目は空欄にせず「未設定」と書く。推測で埋めない
   - いつ・なぜ決めたか分かるものは、その理由も一言添える
   - 見出しに当てはまらないルールは「その他」に書く
3. 「最終更新」の日付を入れ、コミットしてpushする
4. 書き出した項目数と、迷った点を短く報告する

書き出しはメモリの中身を写すだけで、メモリ自体は変更しないでください。
