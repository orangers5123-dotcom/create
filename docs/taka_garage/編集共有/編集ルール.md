# いま有効な編集ルール（クラウド側から見た一覧）

編集連携担当が、inboxに書いた変更をここにまとめて最新の状態に保ちます。手元のClaude Codeのメモリとの差分確認用です。

最終更新：2026-11-04

## 冒頭
- 見どころダイジェスト（約30秒・起承転・1カット1.5秒以内・答えは見せない・1フレーム目が一番強い画）
- アイキャッチ1.5秒以内（BGMを切らない）→ 名乗り3秒以内 → 何の動画かを一言 → 本編は0:40ごろまでに
- 動きのあるフック（カメラに向かってパンチなど）を入れる
- ロゴのオープニング、BGMだけの間は入れない

## 本編
- 本編の最初に一番の見どころ
- 2〜3分おきに再フック（テロップ＋効果音）
- 数字（値段・サイズ・距離など）は毎回同じ位置・同じ見た目で大きく
- 比較画面は位置と色を固定、グレーディングなし（かける場合は全台同じ）、注記を入れる
- PRの部分も通常回と同じテンポ・調子

## 終わり
- 結論はBGMを変えて区切り、表は3秒以上
- 保存用のまとめ表（概要欄にも）
- 関連動画への誘導と、質問形式のコメント促し

## 音
- 声 -10dB／効果音 -20〜-25dB／BGM -30dB前後

## ショート
- **型は `docs/taka_garage/ショートの型_高橋さん完成版.md` に従う**（2026-11-05、高橋さんの完成版から。旧ルールの「0.0秒目から効果音・2秒以上止めない・早回しに効果音」は廃止）
- 見出し「〇〇／〜した結果」を0秒から最後まで出し続ける
- 0秒目は問題の画と本人の声で始める。完成形の画で始めない。見えにくい問題は赤丸で示す
- 声を最初から最後まで途切れさせない。無音・黒い画面・文字だけのカードは入れない
- カットは語りの1フレーズごと（2〜5秒）、動作の切れ目で切る
- 文字は4種類：見出し／字幕／太字の大きい字（話が切り替わる一言）／白い箱（一番伝えたい結果2つだけ）
- 冒頭の問題は、必ず後半で結果として回収する（問題と結果を対にする）
- 人柄が出るつぶやき・失敗を残す
- 最後は本編のサムネカード＋「もっと詳しく見たい人は本編へ！」。関連動画に本編を設定
- 尺30〜50秒。縦1080×1920、元のタイムラインは変えず新しいタイムラインで作る
