# いま有効な編集ルール（クラウド側から見た一覧）

編集連携担当が、inboxに書いた変更をここにまとめて最新の状態に保ちます。手元のClaude Codeのメモリとの差分確認用です。

最終更新：2026-11-04

## 冒頭
- 見どころダイジェスト（約30秒・起承転・1カット1.5秒以内・答えは見せない・1フレーム目が一番強い画）
- アイキャッチ1.5秒以内（BGMを切らない）→ 名乗り3秒以内 → 何の動画かを一言 → 本編は0:40ごろまでに
- 動きのあるフック（カメラに向かってパンチなど）を入れる
- ロゴのオープニング、BGMだけの間は入れない

## 本編
- 本編の最初に一番の見どころ
- 2〜3分おきに再フック（テロップ＋効果音）
- 数字（値段・サイズ・距離など）は毎回同じ位置・同じ見た目で大きく
- 比較画面は位置と色を固定、グレーディングなし（かける場合は全台同じ）、注記を入れる
- PRの部分も通常回と同じテンポ・調子

## 終わり
- 結論はBGMを変えて区切り、表は3秒以上
- 保存用のまとめ表（概要欄にも）
- 関連動画への誘導と、質問形式のコメント促し

## 音
- 声 -10dB／効果音 -20〜-25dB／BGM -30dB前後

## ショート
- 横動画の編集時に、ショート向きの場面に印を付けておく
- 縦 1080×1920。フレームレートは元のタイムラインに合わせる。元のタイムラインは変えず、新しいタイムラインで作る
- 尺は45〜50秒以内（50秒を超えない）
- 構成の型：0〜0.5秒 結果・数字（完成形の画＋短いテロップ＋効果音1発）→ Before（悩み）→ 作業（早回し・1カット1〜1.5秒）→ After（完成形）→ 締め（本編への誘導の一言）。最後の画を冒頭と同じ構図にしてループさせる
- 名乗り・挨拶・ロゴ・「チャンネル登録お願いします」は入れない。答えを全部言わず本編へ行く理由を残す
- テロップは手元の型を優先。位置は上1/3〜中央。下から約670px・右から約190pxには重要な文字を置かない（外部の目安。実機で確認）。1行10文字以内・2行まで、数字は大きく同じ位置
- 音量は横動画と同じ（声 -10dB／効果音 -20〜-25dB／BGM -30dB前後）。BGMは最後まで切らない
- 16:9素材はズーム・位置で人物と主役の物を中央に。動きが欲しい所はゆっくりパンかズーム
- タイトルは冒頭に数字か結果＋短い1文＋【ガレージ秘密基地】などのシリーズ名。「ヤバすぎ」系は使わない
- 関連動画に本編を設定。固定コメントは本編への誘導＋質問形式
- 確認：公開48時間後の再生数を配線・デスク系ショートの中央値4.1万回（全体中央値1.0万回）と比べる。本編の流入元で「ショート」からの視聴が増えたか
