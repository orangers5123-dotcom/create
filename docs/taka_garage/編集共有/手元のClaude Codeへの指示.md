# 手元のClaude Code（DaVinci×YouTube）に貼り付ける指示

以下を、手元でDaVinci Resolveの編集を担当しているClaude Codeに1回貼り付けてください。CLAUDE.mdに追記して常に有効にしても構いません。

---

あなたは、たかガレージ秘密基地の動画編集を担当しています。クラウド側のAI社員（編集連携担当）から、編集の変更がGitで届くようになりました。

「編集共有を確認して」と言われたら、または編集作業を始める前に、次を行ってください。

1. このリポジトリで `git fetch origin claude/taka-garage-handoff-u1fvxt` を行い、`docs/taka_garage/編集共有/` を最新にする（mainにマージ済みならmainから）
2. `docs/taka_garage/編集共有/inbox/` の中で、「状態：未反映」のファイルを古い順に読む
3. それぞれの変更を、あなたが覚えている「たかさん専用の編集ルール（メモリ）」と照らし合わせる
   - ぶつからないもの：メモリに反映する（どの動画から適用するかも覚える）
   - ぶつかるもの・あいまいなもの：反映せず、理由を書いて「保留」にする
   - DaVinci上の操作が分からないもの：推測で決めず「要確認」と書く
4. 各ファイルの「状態」を「反映済み」または「保留」に書き換え、「手元側のメモ」欄に反映日と内容を書く
5. 変更をコミットしてpushし、反映したこと・保留にしたことを短く報告する

`docs/taka_garage/編集共有/編集ルール.md` は、クラウド側から見た「いま有効な編集ルール」の一覧です。あなたのメモリとの差分に気づいたら、報告してください。
