# さぬさんのnote 要点メモ（会社員×週1投稿で登録10万人・広告収益月100万円のロードマップ）

読み込み日：2026-11-03。たかガレージの運用で参照するための要約（本文の転載ではなく要点のみ）。

## 全体の考え方
- 「企画とサムネが8割」。アルゴリズム＝視聴者。攻略法より視聴者の満足（視聴維持率）を上げる
- 続ける力は根性ではなく仕組み。完璧を目指さず完成度70%で出す。ただし音とフレームレートは必ず整える
- 定期投稿は「頻度」より「規則性」が大事。隔週でもペースを固定する

## テーマ・チャンネル設計
- 好き・得意をベースに、稼ぎたい額に応じて需要を掛け算する。流行だけに飛びつかない（AI量産動画の収益化停止の例）
- ジャンルを混ぜず、最初はニッチに特化
- ベンチマーク：シークレットモードで検索→登録者数千〜数万の「現実的なお手本」を1〜3個。見る点は①登録者数 ②直近半年〜1年も投稿・再生が続いているか ③登録者数の3〜4倍以上再生された動画があるか
- 目安：登録者数×10円 ≒ 月の広告収益
- 看板（チャンネル名・アイコン・バナー）で何屋か分かるように。チャンネル名の前半に検索キーワード。バナーに「毎週◯曜◯時更新」
- 初投稿にはボーナスがある。自己紹介動画やテーマ外の動画を1本目にしない

## 動画づくりの順番（5STEP）
1. 企画 → 2. サムネの設計（写真・文字・配置、最低3案）→ 3. 撮影 → 4. 編集 → 5. 予約投稿
- 撮影：1トピックごとにカットを分ける、引き／ミドル／アップ、自然光、揺れ注意
- 編集：カット→アフレコ→BGM→オープニング→テロップ→効果音→書き出し→文字起こし。時間で区切る
- 予約投稿で必ず確認：著作権の申し立て、音量、ミッドロール広告のスロット

## 企画
- 企画は考えるより見つける。登録者1万〜20万人の中堅チャンネルで、登録者の3〜5倍以上再生された動画を探し、自分の経験で作り直す
- 「自分ごと」になる切り口に（例：「香港Vlog #6」→「子連れで楽しめる香港おすすめ6選」）
- 当たった企画は何度繰り返してもいい（視聴者は全部見ていないし覚えていない）

## サムネ
- おしゃれより「伝わる」。サムネは広告に近い。「読むものではなく見るもの」
- メインのコピーは8〜9文字が目安。文字は少なく
- 大事な言葉は左上（視線が最初に行く所）。右下は再生時間で隠れるので重要な情報を置かない
- 写真の主役をはっきり。2025年以降は写真メインのサムネが伸びやすい実感
- 失敗例：キーワードが入っていない／文字が読みにくい（細い・コントラスト不足・ロゴが邪魔）／文字で写真が見えない／言い回しをひねりすぎる／A/Bテストをしていない
- 読みにくいときは影・縁・座布団（長方形）で対処
- 鉄板ワード（「買ってよかった」など）は繰り返し使ってOK
- A/Bテストは理由が明確に違う3案：①検索ワード重視型 ②感情ワード型 ③写真メイン型。4案作って3案を選ぶ
- 一晩寝かせて見直す。サムネに約2時間かける
- GeminiのNano Bananaで構図のアイデア出し→Canvaで仕上げ
- 外注してもいいが、訴求ポイント（言葉と写真の選び方）は自分で握る

## 冒頭と構成（視聴維持率）
- ①見どころダイジェスト → ②内容の説明（20〜30秒）→ ③一番の見どころ
- 30秒で本編をスタート。自己紹介や説明を長くしない
- 本編の最初に一番見ごたえのある内容を置く

## 収益を伸ばした施策
- 動画の長さを段階的に伸ばす：8分以上でミッドロール可。10分程度→1000回あたり約630円、18分程度→約850円。ただし視聴維持率40%超えが目安
- 長さの目安は同ジャンルで登録者の約3倍再生された動画を参考に
- ショートは本編への広告として。月2〜3本で十分、チャンネル全体の収益が約25%アップ。ただし本編を優先
- 「チャンネル登録お願いします」より、①チャンネル内の他の動画へ誘導 ②質問形式でコメントを促す、の方が効く

## 最初の1か月・分析
- 1本目から1か月以内に2〜3本（ショートは含まない）
- 初期は知り合いにチャンネルを教えない（早い離脱が評価を下げる）
- 見る数字は平均視聴維持率くらい。投稿2週間後以降に確認
- 2週間後に「再生数÷登録者数」：何倍も→十分／50〜100%→健闘／20〜50%→普通〜伸び悩み／10%未満→改善点を1つ決めて次で試す
- 黄〜赤が3本中2本続いたら、原因を1つだけ選んで次の1本で試す（①企画がぼやけている ②サムネで見る理由が伝わらない ③テーマから外れている）

## 時間管理
- カレンダーで使える時間を見える化。朝の1時間（5:30〜6:30）を勝負の時間に
- タスクを小分け（「編集」とまとめない）。曜日ごとに作業を固定し、1〜2日の余白
- ポモドーロ（25分＋5分）、通知オフ、物理タイマー
- 月収5万円を超えたら外注を検討（心のゆとりが企画の質を上げる）

## 失敗しやすい設定
- 音量の目安：声 -10dB、効果音 -20〜-25dB、BGM -30dB前後。大きい音が1か所あると全体が下げられることがある
- BGMは有料（Epidemic Sound）で著作権トラブルを避ける。予約投稿で事前に確認
- 広告カテゴリ：アルコール・ギャンブルがデフォルトでブロック。問題なければ解除で単価が上がる可能性（Studio→設定→広告カテゴリ）
- ミッドロールのスロットが自動で入らない不具合あり（約8万円の損失例）。予約投稿で確認

## 2026年の追記：多言語サムネ
- 2026年から言語ごとにサムネを設定できる。日本語からの自動翻訳は英語のみ
- まず英語化（SRTを整えると英語字幕・音声が自動）→英語サムネ→台湾・ドイツなどを追加
- 台湾サムネで日本以外の視聴者が7.2%→21%、新規登録の約4割が対象国から。ドイツはRPMが日本の約1.5倍
- 公開済みの動画にも効く。国内で土台ができてから行う（先にやると海外向けと誤認される）

## よくある質問
- アンチコメントは「チャンネルからユーザーを非表示」
- 顔出しは必須ではないが、声と本人を感じられる映像は武器。AI量産型は信頼を得にくい
- ショートと相性がいいジャンル：料理、DIY・収納・ハンドメイド、メイク、フィットネス（ビフォーアフターや完成形が見える）
