# AI社員の使い方（高橋さん向け・かんたん版）

## 頼み方
Claude Codeでこのリポジトリを開き、ふつうの言葉で「◯◯担当に、△△をお願い」と書くだけです。担当の名前を出さなくても、内容に合う担当が動きます。
迷ったら **「進行管理に、今週やることを整理してもらって」** と言えば、誰に何を頼むかまで決めてくれます。

## 毎週のルーティン（これだけやればOK）
| いつ | 高橋さんがやること | 頼む相手と一言 |
|---|---|---|
| 月曜 | 先週公開した動画のStudioのスクショ（概要・リーチ・エンゲージメント）を貼る | 分析担当「先週の動画を振り返って」 |
| 月曜 | — | 進行管理「今週の予定と、誰に何を頼むか決めて」 |
| 火曜 | — | リサーチ担当「今週伸びている動画を集めて、たかガレージで真似できることを教えて」 |
| 水曜 | 次の企画の候補を1つ選ぶ | 企画担当「この企画で企画書を作って」 |
| 水曜〜木曜 | 企画書でOKを出す | 台本担当「この企画書で台本とショットリストを作って」／サムネ担当「サムネ案を4つ作って」 |
| 木曜 | — | ショート担当「今週のショートの切り抜き場所を選んで」 |
| 随時 | 編集のやり方を変えると決めたら | 編集連携担当「この編集を手元に共有して」 → 手元のClaude Codeに「編集共有を確認して」 |
| 随時 | 案件が届いたら、ガイドラインを貼る | 営業・案件担当「この案件をどう企画にするか考えて」 |
| 月末 | Studioの月間の数字のスクショを貼る | 分析担当「今月の数字を目標と比べて」 |

## 担当一覧
| 担当 | 頼めること |
|---|---|
| 進行管理（taka-producer） | 今週やること、スケジュール、割り振り、引き継ぎメモの更新 |
| リサーチ（taka-researcher） | 伸びている動画・チャンネル・トレンド、真似できること |
| 企画（taka-planner） | 企画書、タイトル案、案件の企画化 |
| 台本（taka-scriptwriter） | 台本、冒頭のフック、ショットリスト、編集の指示 |
| サムネ（taka-thumbnail） | サムネ案4つとラフ画像、A/Bテストの記録 |
| ショート（taka-shorts） | 切り抜き場所、1〜3万円シリーズ、投稿曜日 |
| 分析（taka-analyst） | 動画の振り返り、2週間チェック、月の数字 |
| 営業・案件（taka-sales） | 営業先リスト、営業メール、メディアシート、案件の受け方 |
| 編集連携（taka-edit-liaison） | 決まった編集の変更を手元のDaVinci用Claude Codeへ渡す／手元の編集ルールを受け取って施策を考える |

## 覚えておくこと
- AI社員は前の会話を覚えていません。決まったことは `docs/taka_garage/` のファイル（特に HANDOFF.md とチャンネル基本ルール.md）に残っていれば、次の担当に引き継がれます
- Studioの中身（CTR・維持率・登録者の増減）は外から見られないので、スクショを貼ってもらう必要があります
- ルールを変えたいときは `チャンネル基本ルール.md` を直せば、全員に反映されます
