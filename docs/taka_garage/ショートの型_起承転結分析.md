## 4. 共通する型（たかガレージ用）
- **起（0〜3秒）**：「〜した結果」「〜と思ってた」「〜、コスパ悪い。」のように、問題・思い込み・逆張りを1文で。画は問題が見える物（赤丸で示す）
- **承**：先に結論を言い、作業や実演を本人の声で
- **転**：意外な事実か、人柄の出るつぶやき・失敗
- **結**：冒頭の問題を回収する結果を白い箱で→本編カード
- テーマは「デスク周り・配線・部屋の悩み」が最強。尺は30〜50秒

## 5. 確かめ方
次の4本で型を守り、視聴を続けた割合60%以上・再生数1万回以上になるかを見る。他チャンネルの型（逆張りの1文）は1本試して、視聴を続けた割合で比べる。
